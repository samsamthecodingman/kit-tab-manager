Rules & lists

Grouping rules

"Apply my rules" moves tabs into groups. The first matching rule wins, and rules only move tabs that aren't already in a group.

Title contains
words that appear in the tab's title
Address contains
anything in the web address, like /docs/
Website is
a site like github.com, including its subdomains. You can paste a full address.

My lists

A list is a named set of steps that runs in order from the toolbar menu.

Back up or share

Save your rules and lists to a file, or load them from one. Importing replaces what you have now.
